Features

Built for music collectors: a complete pipeline from sign-in to library.

Platform dashboard

Live login status and VIP badges (VIP / Premium / Black Vinyl) for every platform, with a per-channel refresh button.

🛩️

Anti-detection browser

chrome-driverless hides automation fingerprints: scan QR codes, sign in, solve challenges in a real browser; cookies are exported automatically.

🔎

Search & link parsing

Multi-platform search for songs and playlists; paste any track/playlist/collection/video link and expand it into per-item tasks.

Batch download & retry

Per-task progress, readable failure reasons, one-click retry. QQ Music uses browser vkey direct links; other platforms fall back to yt-dlp + cookies.

Install

All you need is Docker.

1

Create docker-compose.yml

New folder, paste this (music lands in ./downloads):

services:
  web:
    image: ghcr.io/friddle/ytb-dl-web:main
    container_name: gharmonize
    ports:
      - "5174:5174"
    environment:
      - PORT=5174
      - MEDIA_DOWNLOAD_DIR=/music              # default download dir (container path)
      - YTDLP_COOKIES=/data/cookies/cookies.txt
      # proxy for Chinese platforms (optional, leave empty for direct)
      # - HTTP_PROXY=http://192.168.1.2:7890
      # - HTTPS_PROXY=http://192.168.1.2:7890
      # - NO_PROXY=127.0.0.1,localhost
    volumes:
      - ./downloads:/music                     # music output
      - ./data:/data                           # cookies etc.
    restart: unless-stopped
2

Start

docker compose up -d

The image comes from ghcr.io/friddle/ytb-dl-web with the browser (chrome-driverless) bundled — no extra setup.

3

Open the web UI

Visit http://your-nas-ip:5174/ — then head to sign in.

Environment variables

VariableDescription
PORTServer port, default 5174
MEDIA_DOWNLOAD_DIRDefault download directory (container path, must be mounted)
YTDLP_COOKIEScookies.txt path for the download engine, auto-written on login
HTTP_PROXY / HTTPS_PROXYProxy for Chinese platforms; empty = direct
PUID / PGIDContainer user/group ID (align with NAS permissions)
GHARMONIZE_ALLOWED_ORIGINSOrigin allowlist when behind a reverse proxy

Sign in to platforms

All sign-ins happen in the built-in browser — credentials never touch a third party.

1

Open the Home tab

Go to "🏠 Home" — login status of all platforms is auto-checked on page load.

2

Click "Sign in"

The built-in browser opens the platform's login page: Bilibili / QQ Music / NetEase use QR codes from the mobile app; YouTube / Spotify use account sign-in (Google supported).

3

Confirm with "Check"

The card shows ✅ signed in plus VIP badges (VIP / Premium / Black Vinyl). Login state is exported to cookies.txt for the download engine (on startup and every 6 hours).

Download music

Three ways, from discovery to library.

1

Search & download

"🌐 Online" tab: pick platforms → type song/artist → search → multi-select results to download. Search needs no sign-in.

2

Parse links (recommended)

Paste any song / playlist / collection / video link shared from the app → "Parse" → the whole playlist expands into per-item tasks → download all.

3

Progress & conversion

"⬇️ Download" tab shows per-item progress with retry on failure; pick output format and subfolder per batch. Defaults live in "⚙️ Settings"; cover art and lyrics are tagged automatically.

4

Stream it

Once files land in MEDIA_DOWNLOAD_DIR, point Navidrome / Jellyfin / Infuse at the folder and stream everywhere.

FAQ

Do I need to sign in to download music?

Chinese platforms (QQ Music / NetEase / Bilibili) can be searched without signing in; VIP sources require the corresponding account. YouTube and Spotify require sign-in.

Can I download VIP songs?

Yes. Sign in with your VIP / Premium / Black Vinyl account in the built-in browser; once VIP status is detected, those sources become downloadable.

How do I update?

docker compose pull && docker compose up -d. Images are built and pushed by CI automatically, and the app also checks for new versions quietly at startup.

Where does my data live?

Entirely on your own NAS / server: music output and browser profiles (logins) are local volume mounts — nothing is sent to third parties.
